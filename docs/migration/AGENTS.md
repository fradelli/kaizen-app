# Instruções da migração

- O legado privado permanece preservado e não deve ser alterado para acomodar o Kaizen.
- Preserve originais byte a byte quando a tarefa exigir cópia literal.
- Registre origem, caminho, commit, tratamento, hash e exposição no manifesto.
- Exposições permitidas: `PUBLIC`, `REVIEW_REQUIRED` e `DO_NOT_PUBLISH`; o padrão é `DO_NOT_PUBLISH`.
- Conteúdo não aprovado no manifesto não pode entrar no repositório público.
- Corrija primeiro a fonte canônica e depois sincronize documentos derivados.
