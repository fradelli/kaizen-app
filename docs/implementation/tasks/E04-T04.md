O shell final contém somente links `Dieta` e `Treino`, usa `aria-current` na rota ativa, mantém foco visível, não depende de hover e funciona a 320 px e com zoom de 200%. Os placeholders dizem claramente que os dados entram em E06/E07; não simulam refeições ou exercícios. Elementos interativos usam primitives públicas quando elas existirem; não criar clone local para contornar ausência no package.

O shell é um Server Component. Somente a navegação que consulta `usePathname`
forma uma ilha Client. A organização da pasta segue as responsabilidades
normativas de `docs/architecture/TARGET-ARCHITECTURE.md`; nenhuma camada client
pode importar dados ou código server-only.

### Validação E04-T04

- rota `/` redireciona para `/dieta`;
- links funcionam por teclado;
- headings são hierárquicos;
- viewport estreito não produz rolagem horizontal;
- nenhuma página importa JSON, Prisma ou regra de feature ainda.
- `/foundations` e todos os gates de E04-T08 permanecem verdes.
- shell e calendário continuam locais; nenhum export específico do Kaizen é adicionado ao package.

## Riscos e rollback

- **Risco:** duplicar primitive ou token no shell. **Controle:** revisar cada estilo contra os exports públicos e limitar CSS local à composição.
- **Risco:** acoplar o package às rotas do Kaizen. **Controle:** imports fluem do app para `@fradelli/ui`, nunca no sentido inverso.
- **Rollback:** reverter arquivos do shell e restaurar a página anterior, preservando a integração do Design System e `/foundations`.
