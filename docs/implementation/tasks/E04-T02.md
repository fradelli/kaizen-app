## Versões relevantes

- ESLint `9.39.5` e eslint-config-next `16.3.4`
- Prettier `3.9.6`
- Vitest e coverage-v8 `4.1.11`
- Testing Library React `16.3.3` e jest-dom `7.0.1`
- jsdom `30.0.1`
- TypeScript `6.0.3`

ESLint 9 e TypeScript 6 são mantidos nesta tarefa porque os plugins transitivos de
`eslint-config-next@16.3.4` ainda não aceitam ESLint 10 nem TypeScript 7. O alinhamento evita
instalação com peers inválidos e falha de carregamento do `typescript-eslint`.

## Implementação

### Dependências

Ação: **EDIT** em `package.json` e **GENERATE** em `pnpm-lock.yaml` por comandos exatos:

O pacote também declara `"type": "module"` para que Vitest e Vite carreguem as configurações
ESM sem fallback para CommonJS.

```powershell
pnpm add -D -E eslint@9.39.5 eslint-config-next@16.3.4 prettier@3.9.6 vitest@4.1.11 @vitest/coverage-v8@4.1.11 @testing-library/react@16.3.3 @testing-library/jest-dom@7.0.1 jsdom@30.0.1 typescript@6.0.3
pnpm pkg set type="module"
pnpm pkg set scripts.format="prettier --write src *.json *.ts *.mjs"
pnpm pkg set scripts.format:check="prettier --check src *.json *.ts *.mjs"
pnpm pkg set scripts.lint="eslint src eslint.config.mjs next.config.ts vitest.config.ts vitest.setup.ts --max-warnings=0"
pnpm pkg set scripts.typecheck="tsc --noEmit"
pnpm pkg set scripts.test="vitest run"
pnpm pkg set scripts.test:coverage="vitest run --coverage"
```

### `pnpm-workspace.yaml`

Ação: **CREATE** pelo fluxo `pnpm approve-builds`.

```yaml
allowBuilds:
  unrs-resolver: true
```

`unrs-resolver` é uma dependência transitiva de `eslint-config-next` e usa postinstall para
preparar o binding nativo do resolvedor. Nenhum outro script de dependência fica autorizado.

### `vitest.config.ts`

Ação: **CREATE**.

```ts
import path from "node:path";
import { fileURLToPath } from "node:url";

import { defineConfig } from "vitest/config";

const rootDirectory = path.dirname(fileURLToPath(import.meta.url));

export default defineConfig({
  resolve: {
    alias: { "@": path.join(rootDirectory, "src") },
  },
  test: {
    environment: "jsdom",
    setupFiles: ["./vitest.setup.ts"],
    coverage: {
      provider: "v8",
      reporter: ["text", "json", "html"],
      thresholds: {
        lines: 80,
        functions: 80,
        branches: 80,
        statements: 80,
      },
    },
  },
});
```
