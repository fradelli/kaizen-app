# Resumo diário de treino

Use este documento para encontrar a sessão; execute a dose descrita no [plano ativo](../../data/active.json). Este resumo não define uma agenda pública.

## Antes de escolher

1. Consulte sua agenda em ambiente privado.
2. Considere futevôlei e jogo como carga do dia.
3. Aplique as regras de distribuição de [`data/schedule.json`](../../data/schedule.json).
4. Confirme recuperação e tempo disponível.
5. Abra a sessão correspondente no plano ativo.

## Atalhos

| Situação | Sessão |
| --- | --- |
| Inferiores com recuperação suficiente | `lower_a` ou `lower_b` conforme a distribuição privada |
| Inferiores com baixo volume perto do jogo | `lower_b_microdose`, somente quando prevista |
| Superiores com foco em força | `upper_a` |
| Superiores com foco complementar | `upper_b` |
| Preparar superiores | `pre_upper_warmup` |
| Preparar inferiores | `pre_lower_warmup` |
| Preparar futevôlei | `pre_footvolley_warmup` |

## Quando houver pouco tempo

- Use `short_version_target_minutes` quando existir.
- Priorize exercícios marcados como `fundamental`.
- Não reduza descanso de exercícios pesados ou saltos para encaixar mais volume.
- Não transfira complementares omitidos para a sessão seguinte.

## Regras rápidas

- Pernas não vão rotineiramente até a falha.
- Saltos terminam quando a qualidade cai.
- Progressão altera uma variável por vez.
- Exercício novo começa com dose conservadora.
- Aquecimento equivalente não deve ser duplicado.
- Dor persistente, trauma ou sintomas neurológicos exigem avaliação profissional.

Para contexto, consulte o [guia de treino](TRAINING-GUIDE.md), as [regras de domínio](TRAINING-RULES.md) e a [biblioteca de exercícios](../../data/exercises.json).
